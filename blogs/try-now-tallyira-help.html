Try Docs by Ira: TallyIra Help for Voucher Creation

TallyPrime Features
Oct 23, 2026
5 min read
Turn clear transaction documents into draft vouchers, then review before accepting

What is Docs by Ira?

Docs by Ira is an AI-powered TallyPrime plug-in that helps create vouchers from transaction documents in PDF or image format. It can also assist with creating required masters as part of the voucher-creation process. Imported entries should be reviewed carefully; the feature supports data entry but does not replace your approval and accounting checks.

If you are looking for a “Try Now” starting point, begin with one clear, representative document and use the official setup instructions to confirm plug-in availability for your license. Feature access, quotas and plan terms can change, so check the current Tally Solutions portal before registering or purchasing a plan.

Before you try it

  • Use a valid TallyPrime license with an active Tally Software Services (TSS) subscription.
  • Use TallyPrime Release 7.1 or later and complete the Docs by Ira registration and plug-in setup.
  • Keep the required mobile number and email access available for verification steps.
  • Use a readable PDF or image that contains one transaction document. Supported image formats include PNG, JPG and JPEG.
  • Documents should be legible and typed; handwritten documents and documents in languages other than English are not supported according to the current help guide.

A simple first-run workflow

  1. Register for Docs by Ira using the license serial number and complete the required OTP verification.
  2. Update the TallyPrime license and confirm the Docs by Ira plug-in appears as loaded in plug-in management.
  3. Import one clear sample transaction document from your computer or use the supported TallyIra app workflow.
  4. Open the review/imported-transactions report and check the extracted party, date, item, quantity, tax and amount details.
  5. Resolve any missing-master or date exceptions, then verify the draft voucher against the original document before accepting it.

Supported voucher types include Sales, Purchase, Credit Note, Debit Note, Delivery Note, Receipt Note, Sales Order, Purchase Order and Journal Voucher. Limits on file size, batch import and plan quota apply; check the latest official instructions for exact limits.

Where to find TallyIra help

Use the in-product Help menu and the official Tally help pages for setup, supported documents, quota usage and exception resolution. Start with the official Get Started with Docs by Ira guide, then refer to Docs by Ira in TallyPrime for voucher creation and workflow details.

Review is still essential

Always compare the proposed voucher with its source document. Confirm the company, voucher type, party ledger, tax treatment, item allocation and totals. Correct any mismatch before saving or posting, and follow your organisation's normal approval process.

With a clean source document and a careful review routine, Docs by Ira can help reduce repetitive data entry while keeping your accounting workflow under your control.
